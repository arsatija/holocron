NCO+ always means JNCO, SNCO, Company, and Command rank levels combined.

**Why:** User clarified this is a fixed shorthand used throughout the unit.
**How to apply:** Whenever rank-based permissions say "NCO+" or "NCO and above", expand to `[RankLevel.JNCO, RankLevel.SNCO, RankLevel.Company, RankLevel.Command]`.
